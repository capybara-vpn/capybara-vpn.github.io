- **Спокойная приватность** — никаких сложных анкет, серверы в режиме RAM-only без долговременных логов.
- **Поддержка в Telegram** — вопрос, сообщение, ответ. Без тикет-систем.
- **Ваши устройства** — iOS, Android, Windows, macOS, Linux и TV.

## Частые вопросы

**Это вообще законно?**
Да. VPN — это технология шифрования трафика, она легальна и используется банками, корпорациями и обычными пользователями для защиты данных.

**Сколько устройств можно подключить?**
Количество устройств зависит от выбранного тарифа. На одной подписке можно подключить телефон, ноутбук, планшет, ТВ и роутер.

**Точно ли не сохраняются логи?**
Мы не храним историю посещений, IP-адреса и DNS-запросы. Серверы работают в режиме RAM-only без долговременных логов.

**Есть ли ограничения по трафику?**
Нет. Во всех тарифах трафик безлимитный.

**Как оплатить из России?**
Доступны популярные способы оплаты: карты, СБП и другие провайдеры, подключённые к сервису.

**Что если не работает на каком-то сайте?**
Напишите в поддержку — подскажем рабочую локацию или протокол. Обычно помогает смена сервера или обновление подписки.

**Можно ли вернуть деньги?**
Да, предусмотрен простой возврат в рамках правил сервиса. Обратитесь в поддержку с номером платежа.
